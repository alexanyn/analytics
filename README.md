# 📊 Analytics Digest

Автоматический сбор, обработка и доставка аналитического дайджеста в Telegram.

Проект собирает статьи из RSS-источников, дедуплицирует, классифицирует по тематикам и регионам, переводит (при необходимости) с помощью Gemini AI, форматирует в удобный HTML и отправляет в Telegram-канал.

---

## 🚀 Возможности

- Асинхронный сбор из 50+ RSS-источников
- Умная дедупликация заголовков (с кешированием)
- Классификация по 12 категориям (геополитика, экономика, технологии, энергетика, безопасность, PR)
- Перевод и суммаризация текстов через **Gemini 2.0 Flash** (с fallback на `googletrans`)
- Формирование читаемого HTML-дайджеста с гиперссылками на источники
- Отправка в Telegram через `sendRichMessage` с разбивкой на чанки (до 32k символов)
- Оптимизированное расписание: ожидание до 09:00 МСК не более 10 минут (экономия минут GitHub Actions)
- Еженедельная проверка здоровья RSS-источников
- Интерактивный дашборд с графиками и метриками
